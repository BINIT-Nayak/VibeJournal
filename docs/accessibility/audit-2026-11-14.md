# Accessibility audit — 14 November 2026

## Scope and method

Reviewed the shared application shell, authentication, dashboard, journal editor,
history/detail/edit screens, analytics, music, Settings and deletion dialogs.
Used axe-core 4.11.4 in headless Chrome against WCAG 2 A/AA, 2.1 AA and 2.2 AA rules,
plus keyboard assertions and source review. Tested desktop, 390px mobile,
dark Settings and validation/dialog states with a disposable account.

## Findings and fixes

| Finding                                                                                                      | Change                                                                                                                                                                                                  |
| ------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

The existing dashboard/analytics mood chart already provided an expandable table,
missing-day labels and keyboard accessibility. Those alternatives were retained
and checked rather than replaced. Existing form error descriptions, radio labels
and the skip link were also retained and exercised.

## Regression verification

Final result: all 16 page/state scans reported zero violations for the configured
axe rules, and all keyboard assertions passed. Type checking, linting and the
production build also passed.

Run npm run test:a11y with the development server and local PostgreSQL available.
Set PLAYWRIGHT_MODULE to an installed Playwright module if it is not on the
project's module path; the test uses installed Chrome. axe-core is an explicit
development dependency.

The script checks 16 page/state combinations and asserts:

- modal Tab wrapping, Escape cancellation and return focus;
- numeric mood ArrowRight selection and a single tab stop for the radio group;
- optional energy’s unknown/recorded announcement;
- journal validation error association and focus;
- keyboard expansion of the seven-day chart table;
- skip-link focus and mobile editor reflow.

It writes a temporary machine-readable report to
/tmp/vibejournal-accessibility.json. Reports include rule IDs and selectors,
not snapshots of real users' journal text. Accounts are disposable and cleaned up.

## Limits

Automated checks and keyboard/source review do not establish complete WCAG
conformance. Actual VoiceOver/NVDA/TalkBack listening sessions, high zoom across
every content permutation, and provider-controlled Google/iTunes pages were not
tested. Canvas/SVG visual alternatives and live-region changes were reviewed in
code; no claim is made that every assistive-technology/browser combination behaves
identically. Repeat this audit when adding new controls or visual themes.
